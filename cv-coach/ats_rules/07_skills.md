# Skills

## Rules
- Use a dedicated "Skills" section listing technologies, tools, and competencies as plain text — comma-separated or short bullet groups.
- Group skills into labeled categories when the list is long (e.g., "Languages", "Cloud & Infrastructure", "Frameworks").
- Use the exact terminology from the job posting where it matches the candidate's actual experience (e.g., "AWS" vs "Amazon Web Services" — include both if space allows).
- Avoid skill-rating graphics (stars, bars, dials) — ATS cannot parse visual proficiency indicators.
- Do not pad with irrelevant or overly generic skills ("Microsoft Word", "Team Player") unless explicitly requested by the posting.
- Keep the section scannable — avoid long unstructured paragraphs of skills.

## Why It Matters
The Skills section is one of the highest-weighted areas for ATS keyword matching. Clear, plain-text, well-categorized skills maximize match rate without diluting relevance.

## How to Apply
Check that skills are plain text (no graphics), grouped sensibly, and aligned with the target job's required/preferred qualifications.
