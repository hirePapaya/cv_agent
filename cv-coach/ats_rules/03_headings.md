# Section Headings

## Rules
- Use standard, literal section names: "Professional Summary", "Work Experience" (or "Experience"), "Education", "Skills", "Certifications".
- Avoid creative or branded headings ("My Journey", "What I Bring to the Table") — ATS keyword matching relies on conventional labels.
- Format headings as plain text, ideally using built-in heading styles (Word "Heading 2/3") rather than manual font tricks (bold + all caps + larger size achieved via text boxes).
- Keep heading order conventional: Contact → Summary → Experience → Education → Skills → (optional sections).
- Do not nest critical headings inside tables, columns, or graphic elements.

## Why It Matters
ATS systems map resume sections to structured fields (e.g., "Experience" → work history) using heading text. Non-standard or stylized headings can prevent correct categorization, even if the content itself is fine.

## How to Apply
Verify each major section uses one of the recognized heading names and that headings are real text elements, not images or decorative shapes.
